# ProofNet Frontend (Phase 1)

This directory contains the Phase 1 frontend-only shell for ProofNet.

## Scope

- Landing page
- Verification input form
- Verification status panel
- Final result card

No AI, blockchain, database, authentication, or backend integration is implemented in this phase.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000
